# Test ERP 项目规则

> 版本：v1.0  
> 生效日期：2026-05-05  
> 维护人：Test ERP Team

---

## 一、模块分工与职责

### trae_test 模块
- 负责测试用例生成、测试场景分析、测试数据生成、测试用例模板管理
- 核心工具：`modules/trae_test/utils/` 目录下的各类工具

### auto_test 模块
- 负责测试环境配置、测试脚本执行、测试结果收集与分析
- 核心组件：`modules/auto_test/core/`、`drivers/`、`pages/`、`testcases/` 等

---

## 二、环境安全红线

1. **绝对禁止**：在任何生产环境执行自动化脚本
2. **允许环境**：UAT 测试环境、内网测试环境
3. **环境验证**：所有测试脚本必须先验证当前环境，确认非生产环境后才能执行
4. **敏感信息保护**：配置文件中的真实密码、API 密钥等绝对禁止提交到 Git

---

## 三、工作流程

### 测试用例生成流程
1. 检索业务知识库
2. 梳理业务流程
3. 生成测试用例
4. **调用 AuditAgent.audit_test_cases() 审核字段值**
5. **审核通过后**再导出为标准格式
6. 审核**未通过则必须修复后重新审核**，禁止跳过

### 自动化测试执行流程
1. 配置测试环境
2. 准备测试数据
3. 执行测试脚本
4. 收集测试结果
5. 生成测试报告

---

## 四、工作成果归档

- 工作成果统一归档至 `workspace/{yyyymmdd}/` 目录
- 正式成果存入 `formal/`，草稿存入 `draft/`
- 日期格式严格使用 `yyyymmdd`（8 位数字，无横杠）
