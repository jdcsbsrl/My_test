# 历史资料登记索引

## 1. 用途与边界

本文件登记 `workspace/` 中已识别的重复、相互矛盾、失效或非权威资料，并记录它们之间的取代关系。登记范围只包含路径、状态和关系，不复制工作簿内容、运单信息或个人数据。

- 只登记，不删除、不移动、不改写任何历史文件；`workspace/` 历史交付永久保留。
- 新产物不得沿用本文标记为「历史」「非权威」「待确认」的做法，统一按 [PROJECT_ARTIFACT_PLACEMENT.md](PROJECT_ARTIFACT_PLACEMENT.md) 现行规则产出。
- 历史工作簿不批量升级到当前模板；模板唯一来源是 `ExcelGenerator` 的固定模板，只有新交付使用。
- 「较晚版本」只按路径日期、文件时间和体积推断，未逐表核对内容；需要以某一版为准时必须人工确认。
- 知识库内容一律通过 `KnowledgeRetriever` 获取，`workspace/` 下的知识副本不得作为 Agent 数据源。

## 2. 目录结构差异

历史交付存在两套目录结构，均按历史保留：

| 结构 | 示例 | 状态 |
|------|------|------|
| 月份/日期 两级 | `202605/20260511/需求1001366-物流渠道搜索优化.xlsx` | 历史结构，与现行 `workspace/YYYYMMDD` 扁平规则不同 |
| 日期 一级（现行） | `20261022/01_empty_file.xlsx` | 现行结构 |
| 日期下带子目录 | `202607/20260731/draft/`、`202607/20260731/formal/`、`20261022/库存SKU导入失败样本_20261022/` | 历史做法，现行规则禁止在日期目录下再建 `draft/`、`formal/` 或模块子目录 |

新交付只使用一级日期目录，不沿用子目录和月份层级。

## 4. 库存 SKU 导入失败样本（20261022）

同一套失败样本存在三处副本，内容同名同批：

- `20261022/*.xlsx`（散落副本，含 `01_empty_file.xlsx` 至 `23_new_main_sku_bad_format.xlsx`）
- `20261022/库存SKU导入失败样本_20261022/*.xlsx`（同名归集副本）
- `20261022/库存SKU导入失败样本_20261022.zip`（同批打包）

说明文件同样存在两份：`20261022/库存SKU导入失败样本说明.md` 与 `20261022/库存SKU导入失败样本_20261022/库存SKU导入失败样本说明.md`。

这些样本的用途是验证导入校验分支（空文件、损坏文件、表头不匹配、字典不匹配、字段格式错误、重复 SKU 等），不是业务交付物。需要引用时以归集目录为入口，散落副本和 zip 标记为重复件，保留不动。`20261022/` 下的 `07_attribute_dictionary_mismatch_v2.xlsx` 与 `07_attribute_valid_control.xlsx` 是同一场景的变体，登记为同组，不判定其中哪一份为规范版本。
